# 数据需求收集清单

> v6.0 ｜ 编制日期：2026-09-02 ｜ 用途：按此清单逐项收集数据，拿到一项勾一项
> 分工原则：**只有第①类进模型训练**；第②类用于排除假异常；第③类用于提升结论可信度
> 关联文档：[研究计划书](研究计划书.md) ｜ [数据盘点](数据盘点.md)

## ① 模型训练数据（必须，决定方法能不能跑）

- [ ] **1.1 流体长序列日值（水氡、水位）——最高优先级**
  - 范围：巧家周边及川滇断裂带（昭通—鲁甸断裂、小江断裂、则木河断裂沿线）流体台站
  - 要求：**2015 年起**（训练期 ≥8 年）、覆盖 ≥3 个 M≥5 震例、缺测率 <10%
  - 已有底子：昭通SK3井、西昌32井 2025-01 起已有；西昌32井水氡 2015 起已有
  - 渠道：川滇国家地震科技创新实验场数据共享；云南/四川省地震局前兆台网中心；指导老师协调
- [ ] **1.2 回溯数据补齐**：昭通SK3井（53034）、昭通渔洞（53168）的 2022–2024 年日值
  - 用途：让主分析台站训练期从 1 年扩到 4 年以上
- [ ] **1.3 高频数据（小时值/分钟值）**
  - 用途：短临"突跳"异常在日值上只占 1–2 个点，高频才能发挥 CNN 局部特征优势，也是超出参照文献的点
  - 渠道：同 1.1，申请时明确要"分钟值/小时值"
- [ ] **1.4 水温序列**（与水氡同井同步）
  - 用途：第三互证参数（文献设计）；优先 SK3 井深层水温以外的有变化测项

## ② 干扰排除数据（必须，决定结论能不能立）

- [x] **2.1 西昌站气象三要素日值** ✅
  - 存放：`OriData3/西昌.csv`，56571 站，覆盖 2010-01–2026-08，三要素零缺测
  - 注意：降水 2010–2019 单位为 0.1mm，解析时需 ÷10 统一
  - 仍需：**昭通站**气象日值（用于 SK3 井干扰排除，渠道同上）
- [ ] **2.2 湿度、蒸发量**（增强，同 2.1 渠道）
- [ ] **2.3 仪器标定与检修记录**
  - 内容：氡仪换源/换管/标定时间、水位仪校准记录、台站改造史
  - 用途：排除仪器造成的阶跃型"假异常"（比气象干扰更隐蔽、评审更爱问）
  - 渠道：台站/台网中心运维记录，随 1.1 一并向台站索取
- [ ] **2.4 人为活动记录**：观测井周边工程施工、抽水、灌溉变化情况
- [ ] **2.5 区域水文背景**：国家地下水监测工程邻近井水位（中国地质环境监测院）
  - 用途：区分"区域水文过程"与"台站局部异常"，做对照层

## ③ 验证与论证数据（增强，决定论文高度）

- [x] **3.1 地震目录** ✅
  - 存放：`OriData3/earthquake_catalog.csv`，USGS API 下载，819 事件（M≥3，2015–2026，川滇交界）
  - 重点震例：巧家 2026-01-19 M5.2（震中距 64km）、2025-10-11 M5.2（70km）、2024-04-06 M5.0（69km）
  - 详情见 [地震目录说明](地震目录说明.md)
  - 待补充：重点 M≥5 震例的震源机制解（GCMT / USGS moment tensor，逐例查询，公开可得）
- [ ] **3.2 钻孔应变数据（四分量）——最想要的一张牌**
  - 范围：川滇钻孔应变台网，与流体台站同期的日值/分钟值
  - 用途：实测应力对照——异常时段应变是否同步变化，把"构造指示"从推断变成实测
  - 渠道：中国地震局地壳应力研究所 / 实验场共享
- [ ] **3.3 GNSS 速度场 / 应变率场 + 活动断层矢量图**
  - 渠道：中国地壳运动观测网络（公开）；国家地震活动断层研究中心（公开）
  - 用途：空间对照分析底图（异常台站是否位于高应变率区/断层上盘）
- [ ] **3.4 水化学 + 同位素采样（一手数据，经费可覆盖）**
  - 内容：异常时段前后对 SK3 井/泉采样测 δ18O/δD、氚、主离子、（条件允许）He 同位素
  - 用途：一次性区分"降水稀释/浅部混合" vs "深部流体上涌"，文献做不到的一手证据
  - 渠道：联系有测试条件的实验室（委托业务费）；采样方案找指导老师设计
- [ ] **3.5 断层带土壤气剖面（CO₂/H₂/土壤氡）**
  - 用途：把"点"观测扩展成跨断层"线"证据；野外工作量小，适合本科生团队
  - 渠道：自行组织野外测量，需测氡仪/气相色谱支持
- [ ] **3.6 同震响应标定资料**
  - 内容：云南历史大震中有水震波/阶变记录的井的记录
  - 用途：标定各观测井的"响应灵敏度"（对多远、多强的地震有响应），替代通用 M–D 经验公式
