## 1. 总体设计

### 1.1 两阶段流水线

```
阶段一（回归）：时序预测
  输入  X = 过去 60 天的多元流体序列窗口      形状 [batch, 60, n_vars]
  输出  ŷ = 下一时刻水氡浓度（标量回归）

阶段二（无监督异常检测）：
  输入  r = y_true − ŷ（预测残差序列）
  输出  LOF 得分 + 二值异常标记（分位数阈值）
```

- 监督信号只来自序列自身（自回归），**不需要异常标签**——震例少、无标注，监督分类不可行。
- 地震目录（发震时刻、震级、震中距）只用于**结果分析阶段**的异常-地震对应，不进入训练。
- 最终结论由**多参数互证 + 气象干扰排除 + 震例时序对应**三道关支撑，不靠单一指标。

### 1.2 两条分析路线

| 路线 | 主战场 | 核心数据 | 侧重点 |
|------|--------|----------|--------|
| A | 西昌32井 | 水氡11年 + 西昌气象 + 地震目录 | 方法验证（长训练期、干扰排除、异常识别） |
| B | 昭通SK3井 | 四参数（氡/汞/水温/水位）1.5年 + 地震目录 | 双流体消融实验、多参数互证 |

先用路线 A 跑通全流程，再切路线 B 做消融补充，两条线并行互证。

## 4. 阶段 2：基线复现（待执行）

**目标**：用最简单的模型跑通"训练→预测→评估"全链，用文献数值做**健全性检查**。

### 基线集合

| 模型 | 配置 | 文献R²(测试集) | 用途 |
|------|------|----------------|------|
| naive（持久性） | 昨天=今天 | — | 下界 |
| RF | 100树、max_depth=100、min_leaf=5 | −2.38 | 复现单一模型 |
| LSTM | 1层LSTM+2全连接，60天窗，dropout0.3，Adam | 0.58 | 复现单一模型 |
| LSTM-RF | LSTM末时刻隐状态→RF回归 | 0.85 | 复现文献最优 |

**健全性检查**：不必数值相同（不同井不同数据），但**相对排序必须一致**：RF崩→LSTM降→LSTM-RF好。排序不符说明管线有bug。

**数据**：西昌32井水氡（11年长序列）。

### 验收

四个基线全部完成；排序与文献一致；评估指标函数与文献公式逐项核对。

## 5. 阶段 3：CNN-LSTM 与消融实验（待执行）

**目标**：回答"水位信息能否提升水氡预测"——联合建模必须有实证。

### CNN-LSTM 结构

```
Input [B, 60, n_vars] → Conv1D(64,k3,same)+ReLU → MaxPool(2)
→ Conv1D(32,k3,same)+ReLU → LSTM(64) → Dropout(0.3) → Dense(32) → Dense(1)
```

优化器 Adam，损失 MSE，早停(patience=10)；超参网格搜索：hidden {32,64,128} × kernel {3,5} × 窗口 {30,60,90}。

### 消融实验（核心创新点实证）

| 组 | 输入 | 输出 | 检验假设 | 数据 |
|----|------|------|----------|------|
| A | 水氡 | 水氡 | 单变量基线 | 西昌32井 |
| B | 水位 | 水位 | 单变量基线 | SK3井 |
| C | 水氡+水位 | 水氡 | 联合增益 | SK3井 |

每组 ≥5 随机种子，报均值±标准差；C 与 A 做比较；按时间顺序划分（**禁止随机打乱**）。

### 验收

C优于A（或如实记录不显著）；每组结果可复现；结论不依赖单次运行。

## 6. 阶段 4：残差 LOF 异常检测（待执行）

**目标**：从最优模型的残差里提取候选异常事件。

### LOF 方法（对齐文献口径）

```python
lof = LocalOutlierFactor(n_neighbors=k, novelty=True)
scores = -lof.score_samples(X)  # 分数越大越异常
threshold = np.quantile(scores, quantile)
```

- **参照口径**：对残差序列自身打分（自参照novelty），高分位数者判异常——**不用训练段当参照**（冒烟测试教训）；
- **k 值策略**：基准√n，界于样本量1%~10%；残差小k(5~25)、原始序列大k(20~60)、水位中k(10~30)；
- **NaN处理**：含NaN的特征行**整行丢弃**（禁止插值——插值伪造常数段会毒化LOF密度到1e9量级，冒烟测试教训）；
- **阈值敏感性**：扫 {0.98, 0.985, 0.987, 0.99, 0.995}，报告异常点数与Jaccard稳定性。

### 事件聚合

相邻异常点间隔 ≤3 天合并为"异常事件"，输出事件表（起止日期、峰值得分、持续天数）。

### 验收

敏感性扫描落盘；事件表格式统一；抽查2–3个事件与原始曲线吻合。
