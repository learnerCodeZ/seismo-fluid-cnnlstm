```
USGS API: earthquake.usgs.gov/fdsnws/event/1/query
参数：starttime=2015-01-01, endtime=2026-09-03
      minmagnitude=3, minlat=24, maxlat=36, minlon=98, maxlon=108
```

## 5. 震中距计算方法

公式参照文献（Elmaghraby & Lotfy 2009）经验关系 M/D = 1.93 + 3.58 × log₁₀(D)，但实际震中距直接用球面距离公式：

```python
from math import radians, sin, cos, sqrt, atan2
def haversine_km(lat1, lon1, lat2, lon2):
    R = 6371.0
    dlat, dlon = radians(lat2-lat1), radians(lon2-lon1)
    a = sin(dlat/2)**2 + cos(radians(lat1))*cos(radians(lat2))*sin(dlon/2)**2
    return R * 2 * atan2(sqrt(a), sqrt(1-a))

# 例：巧家→2026-01-19 M5.2
haversine_km(26.9, 102.9, 27.1457, 103.4200)  # ≈ 64km
```

## 6. 使用方式

- **阶段5异常-地震对应**：每个异常事件取后 N 天（建议 N=90 天，参照文献设计）窗口，筛窗口内是否有 M≥4 或 M≥5 事件并计算震中距；
- **震例筛选**：以各流体台站为圆心、按震级-震中距经验关系筛选目标震例（替代通用 M–D 公式，用实际井-震距离）；
- **震源机制解**：对重点震例（M≥5，震中距 < 500km）的机制解需额外从 GCMT（earthquake.globalcmt.org）或 USGS moment tensor 查询（公开可下），用于讨论"走滑 vs 逆冲→异常形态差异"（参照刘慧文献 §3.3.2）。

## 7. 已知局限

- USGS 震级以 mw/mb 为主，与中国台网的 Ms 可能有 0.1–0.3 的系统偏差，做时间对应不影响结论，但论文引用时注明震级来源；
- USGS 定位精度在青藏高原东缘约 ±5–10km，对震中距 > 100km 的事件无影响；
- 该目录覆盖 2015–2026，与西昌32井水氡（2015–2026-05）完全对齐；SK3 井（2025–2026-06）需要 2025–2026 子集，已包含在内。
