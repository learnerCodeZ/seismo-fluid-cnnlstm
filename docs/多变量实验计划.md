# 多变量实验计划

> 编制日期：2026-09-04 ｜ 状态：计划阶段，待执行
> 目标：在西昌32井上做多变量对比实验，验证不同输入组合的预测效果

---

## 一、实验设计

### 1.1 变量组合

| 组 | 输入变量 | 输出 | 说明 |
|----|----------|------|------|
| A | 水氡 | 水氡 | 单变量基线（已完成，R²=0.6748） |
| B | 水位 | 水位 | 单变量基线（待做） |
| C | 水氡+水位 | 水氡 | 双变量联合（待做） |
| D | 水氡+水位+降水+气温+气压 | 水氡 | 多变量探索（待做） |

### 1.2 窗口选项

- 15天、30天、45天、60天（默认）、90天、120天
- 每个变量组合×每个窗口 = 一组实验

### 1.3 模型选择

- CNN-LSTM（主模型）
- LSTM-RF（对照组）

### 1.4 评价指标

- RMSE、MAE、MAPE、R²（与参照文献一致）
- 消融实验：C vs A（双变量 vs 单变量水氡）→ 验证水位是否带来增益
- D vs C（加入气象特征 vs 仅双流体）→ 验证气象特征是否带来增益

### 3.2 变量选择下拉框选项

```html

    <option value="radon">单变量 - 水氡</option>
```

### 3.3 交互逻辑

```
用户选择变量组合
    ↓
前端请求 /api/predictions/{station}/{vars}/{window}
    ↓
后端加载 results/{station}_{vars}/window_{window}/ 下的数据
    ↓
返回 JSON（预测值、观测值、残差、异常点、指标）
    ↓
前端 ECharts 更新图表
    ↓
用户切换变量 → 重复以上流程
```

### 3.4 图表展示

- **主图**：预测值 vs 观测值（三条线：观测值、CNN-LSTM、LSTM-RF）
- **残差图**：各模型残差对比
- **指标卡**：显示当前选择的 R²、RMSE、MAPE、异常事件数
- **窗口对比图**：柱状图展示不同窗口下的 R² 和事件数
- **变量对比图**（新增）：柱状图展示不同变量组合下的 R² 和事件数

## 六、预期结果

### 6.1 消融实验预期

| 对比 | 假设 | 预期结果 |
|------|------|----------|
| C vs A | 水位信息提升水氡预测 | C 的 R² > A 的 R²（如果假设成立） |
| D vs C | 气象特征提升预测 | D 的 R² > C 的 R²（如果假设成立） |
| B vs A | 水位比水氡更易预测 | 不确定，需要实验验证 |

### 6.2 窗口大小预期

- 小窗口（15天）：更敏感，但噪声大
- 大窗口（120天）：更稳定，但滞后严重
- 最优窗口：可能在 30~60 天之间（基于已有实验）

### 6.3 异常检测预期

- 双变量异常事件数可能比单变量多（因为两个变量都可能触发异常）
- 多变量互证：水氡和水位同时出现异常 → 更可信
