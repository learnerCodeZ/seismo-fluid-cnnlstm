# Web 可视化计划

> 编制日期：2026-09-03 ｜ 核心功能：滑动窗口可调的预测+异常检测交互平台
> 技术栈：FastAPI（后端）+ ECharts（前端图表）+ 原生 HTML/JS

---

## 一、核心设计：滑动窗口可调

### 窗口选项

| 窗口 | 含义 | 预期效果 |
|------|------|----------|
| 15天 | 只看最近半个月 | 对突变更敏感，但噪声大 |
| 30天 | 最近一个月 | 平衡敏感度和稳定性 |
| 45天 | 最近一个半月 | 较稳定，突变响应稍慢 |
| **60天** | 最近两个月（默认） | 最稳定，对突变响应最慢 |

用户选窗口 → 后端加载对应预训练模型的结果 → 图表实时更新。

### 为什么可调

不同窗口大小适合不同场景：
- 调小窗口（15天）：想找"最近有没有异常"时用
- 调大窗口（60天）：想找"长期趋势有没有变化"时用
- 对比多个窗口：如果某个异常在所有窗口都出现 → 更可信；只在小窗口出现 → 可能是噪声

## 二、预训练方案

### 需要跑的实验

在西昌32井水氡上，每个窗口大小跑一遍完整流程：

| 窗口 | 模型训练 | LOF异常检测 | 需要的时间 |
|------|----------|-------------|------------|
| 15天 | CNN-LSTM + LSTM-RF 基线 | 残差LOF → 事件聚合 | ~3分钟 |
| 30天 | CNN-LSTM + LSTM-RF 基线 | 残差LOF → 事件聚合 | ~3分钟 |
| 45天 | CNN-LSTM + LSTM-RF 基线 | 残差LOF → 事件聚合 | ~3分钟 |
| 60天 | ✅ 已完成 | ✅ 已完成 | 0 |

总计约 9 分钟，可以一次批量跑完。

### 3.2 交互逻辑

```
用户选择窗口大小
    ↓
前端请求 /api/predictions?window=30&station=SCXC32&model=cnn_lstm
    ↓
后端加载 results/window_30/ 下的数据
    ↓
返回 JSON（预测值、观测值、残差、异常点、指标）
    ↓
前端 ECharts 更新图表
    ↓
用户切换窗口 → 重复以上流程
```

### 3.3 关键交互

1. **窗口切换**：下拉框选 15/30/45/60 → 图表实时刷新
2. **模型切换**：CNN-LSTM / LSTM-RF / RF 三选一 → 预测曲线切换
3. **异常点点击**：点击红色异常点 → 弹出详情（时段、得分、气象数据、地震对应）
4. **窗口对比**：柱状图展示四个窗口的 R² 和事件数差异

## 四、API 设计

| 端点 | 方法 | 参数 | 返回 |
|------|------|------|------|
| `/api/windows` | GET | — | 可用窗口列表 [15,30,45,60] |
| `/api/summary/{window}` | GET | — | summary.json（指标+事件列表） |
| `/api/predictions/{window}` | GET | model | {dates[], y_true[], y_pred[], residual[]} |
| `/api/anomalies/{window}` | GET | — | {events[], scores[], threshold} |
| `/api/metrics` | GET | — | 四个窗口的指标对比表 |
| `/api/stations` | GET | — | 可用台站列表 |

## 六、实现步骤

### 步骤 1：预训练多窗口模型（9分钟）

写一个 `run_multi_window.py`，批量跑 15/30/45/60 四个窗口：
- 每个窗口：加载数据 → 滑窗 → 训练 CNN-LSTM → 残差 LOF → 事件聚合 → 生成 summary.json
- 结果存到 `results/window_{15,30,45,60}/`

### 步骤 2：搭建 Web 骨架（半天）

- `web/app.py`：FastAPI + 静态文件服务
- `web/static/index.html`：主页框架（控制栏 + 图表区 + 指标卡 + 事件列表）
- `web/static/js/app.js`：窗口切换逻辑（下拉框 → fetch API → 更新图表）

### 步骤 3：图表实现（半天）

- `charts.js`：ECharts 封装（预测对比图、残差图、异常得分图、窗口对比柱状图）
- 图表响应式：窗口切换时自动刷新，保持坐标轴范围一致

### 步骤 4：异常详情交互（半天）

- 点击异常点 → 弹出详情卡片（时段、得分、气象数据、地震对应）
- 窗口对比柱状图（四个窗口的 R² 和事件数并列显示）
