# data/ 数据目录说明

本目录存放项目的数据文件。`clean/` 子目录下的文件由数据管道程序生成，**禁止手动修改**。

---

## 目录结构

```
data/
├── README.md           ← 本文件
└── clean/              ← 清洗后数据（程序生成）
    ├── long.csv        ← 统一长表（66,034行）
    └── dataset_info.csv← 序列级质量一览表（113条序列）
```

---

## 文件说明

### 1. `clean/long.csv` — 统一长表

**用途**：所有台站、所有测项的时序数据，是模型训练和可视化的数据源。

**格式**：每行一条记录（一个台站一天一个测项的观测值）

| 列名 | 说明 | 示例 |
|------|------|------|
| `station_id` | 台站编号 | `SCXC32`, `53001` |
| `station_name` | 台站名称 | `西昌32井`, `昆明基准地震台` |
| `item_code` | 测项代码 | `4112`, `4211` |
| `item_name` | 测项名称 | `水位观测`, `氡浓度观测` |
| `freq` | 数据频率 | `daily`, `hourly` |
| `source` | 数据来源 | `oridata`, `oridata2` |
| `date` | 观测日期 | `2024-01-28` |
| `value` | 观测值 | `22.8` |
| `quality_flag` | 质量标记 | `raw`, `agg` |

**统计**：
- 总行数：66,034
- 台站数：42
- 测项类型：水位、水温、氡浓度、汞浓度、氢浓度等
- 时间范围：各台站不同（见 dataset_info.csv）

### 2. `clean/dataset_info.csv` — 序列级质量一览表

**用途**：每条序列（台站×测项）的质量统计，用于快速筛选可用数据。

**格式**：每行一条序列

| 列名 | 说明 | 示例 |
|------|------|------|
| `station_id` | 台站编号 | `SCXC32` |
| `station_name` | 台站名称 | `西昌32井` |
| `item_code` | 测项代码 | `4211` |
| `item_name` | 测项名称 | `氡浓度观测` |
| `freq` | 数据频率 | `daily` |
| `source` | 数据来源 | `oridata2` |
| `n_days` | 总天数 | `4143` |
| `n_valid` | 有效天数 | `4143` |
| `n_missing` | 缺测天数 | `0` |
| `n_imputed` | 插补天数 | `0` |
| `missing_ratio` | 缺失率 | `0.0` |
| `quality_flag` | 质量标记 | `usable` |
| `date_start` | 起始日期 | `2015-01-01` |
| `date_end` | 结束日期 | `2026-05-05` |
| `train_end` | 训练集结束 | `2024-01-27` |
| `test_start` | 测试集开始 | `2024-01-28` |
| `test_end` | 测试集结束 | `2026-05-05` |

**统计**：
- 序列总数：113
- 可用序列（`usable`）：大部分
- 项目主序列：西昌32井 氡浓度（`SCXC32`，4143天）
