## 一、CNN-LSTM 是什么？在本项目里怎么用？

CNN-LSTM 是两种神经网络的组合：**CNN（卷积神经网络）负责提取局部特征，LSTM（长短期记忆网络）负责理解时间依赖关系**。

### 两个部件各自干什么

**CNN（卷积神经网络）**：原本是为图像识别设计的——它用一个小窗口（卷积核）在数据上滑动扫描，每次只看一小片区域，提取局部特征。在我们的场景里，"一小片区域"就是连续几天的水氡值，CNN 学到的是"什么样的局部形态有意义"——比如突跳、阶变、短时起伏。这正是地震前兆最需要抓的模式。

**LSTM（长短期记忆网络）**：专门处理时间序列的神经网络。它有一个"记忆"机制，能记住很久以前发生的事——比如去年这个时候的水氡是多少、上个月的趋势是什么。普通模型只看最近几天，LSTM 能看到几十天甚至几百天前的信息，捕捉长期依赖。

### 为什么组合在一起

单独用 LSTM：能理解时间趋势，但对局部突变（比如某天突然跳变）反应慢，容易"平滑"掉。

单独用 CNN：能抓局部形态，但不知道这个形态在时间序列里的前后文（不知道这个突跳是在上升趋势里还是下降趋势里）。

组合起来：CNN 先把每一天的"局部形态"提取出来（这个特征向量包含了"最近几天长什么样"的信息），LSTM 再把这些特征按时间顺序理解（"这个突跳出现在什么趋势背景下"）。**CNN 看形态，LSTM 看趋势，互补。**

### 本项目怎么用

```
输入：过去 60 天的水氡（和水位）序列  →  [batch, 60, n_vars]
  ↓
Conv1D(64)：扫描局部形态，提取突变特征
  ↓
Conv1D(32)：进一步提炼
  ↓
LSTM(64)：理解这些形态在时间上的演变规律
  ↓
输出：预测明天的水氡浓度
```

预测值和实际观测值的差异（残差）越大，说明发生了模型没见过的扰动——异常检测（LOF）找的就是这种点。

### 和参照论文的区别

刘慧论文用的是 LSTM-RF（LSTM 提特征 → 随机森林回归），两段式，RF 不参与梯度传播，模型无法整体优化。我们的 CNN-LSTM 是端到端训练，误差信号从头传到尾。CNN 的卷积核是显式的局部形态提取器，这是 LSTM-RF 没有的能力。

## 二、西昌32井和昭通SK3井是什么关系？

两个**独立的观测站**，在不同城市（相距约300km），我们用来做不同的事：

| | 西昌32井 | 昭通SK3井（53034） |
|---|----------|-------------------|
| 地点 | 四川西昌 | 云南昭通 |
| 数据 | 只有水氡（+气氡） | 水氡 + 水位 + 水温 + 汞（四参数） |
| 时间跨度 | 11年（2015–2026） | 1.5年（2025–2026） |
| 气象配对 | 西昌气象站完全对口 ✅ | 无昭通气象 ❌ |
| 项目角色 | 方法主战场（长训练期、干扰排除） | 消融实验主战场（双流体、多参数互证） |

**为什么需要两个**：西昌有长序列但只有一个变量（水氡），能做方法验证和干扰排除，做不了"联合建模"消融；SK3 有四个参数但只有 1.5 年，能做消融和多参数互证，但训练期太短、没有配对气象。两者互补——一条线证明"方法对"，另一条线证明"联合建模有价值"。

**共同点**：都在巧家 2026-01-19 M5.2 地震的监测范围内（西昌约 300km，SK3 约 60km），两条线最终指向同一个震例，结论互相印证。

## 三、消融实验是什么？

消融实验（ablation study）是机器学习论文的标准做法，一句话解释：**把模型的某个部件拆掉，看性能下降多少，以此证明这个部件有用。**

在本项目中，CNN-LSTM 可以同时接收水氡和水位两个变量。消融实验就是：

| 组 | 输入 | 目的 |
|----|------|------|
| A | 只喂水氡 | 单变量基线 |
| B | 只喂水位 | 单变量基线 |
| C | 水氡 + 水位一起喂 | 联合模型 |

三组用完全一样的模型结构、参数、数据划分，唯一区别是**输入变量不同**。

如果 C 的预测精度明显优于 A，就能说"水位信息确实提升了水氡预测"——这是"联合建模有价值"的**实证**。如果 C 和 A 差不多，就如实报告，创新点转移到别处。

**为什么叫"消融"**：原意是"把模型的一部分烧掉（ablate）看影响"，类比医学里烧灼组织的手术。整个领域统一译作消融实验。

### 依据

**刘慧论文里没有做消融实验**。他们做的是**模型比较**（RF vs LSTM vs LSTM-RF），不是输入变量比较——三个模型都只用水氡单变量，水位和水温只在后面的异常检测阶段做"时间对应"，不参与模型训练。也就是说，论文的多参数是"事后拼接"（各自建模→各自检测→时间对上就算互证），不是"模型内融合"。

消融实验是我们自己的设计，依据是机器学习领域的通用方法论（ablation study 是顶会论文的标准做法，ICML/NeurIPS/ICLR 的审稿人会要求"消融以证明每个组件的贡献"）。在我们的场景里，消融实验要回答的问题是：把水氡和水位一起喂给 CNN-LSTM（模型内融合），比只喂水氡（单变量）好多少——这个问题刘慧论文没有回答，因为他们的框架（LSTM-RF 级联）本来就是单变量的，结构上不支持双变量输入。

所以消融实验既是本项目相对参照论文的**增量**（融合位置从"事后对应"前移到"模型内"），也是答辩时回答"你做了什么新东西"的核心证据。
